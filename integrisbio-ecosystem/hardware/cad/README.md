# hardware/cad

STEP and STL files for the ChronoCase carrier pod and Verity cartridge enclosures.

Binary CAD files are not generated by this code repository — this directory is where the team's
Fusion 360 / SolidWorks exports should be committed once the two-piece 3D-printed chassis
(described in the README's "Conrad Challenge: Achievable MVP Implementation" section) is designed.

Suggested contents once modeling begins:

- `chronocase_carrier_v1.step` — main carrier shell (source CAD)
- `chronocase_carrier_v1.stl` — print-ready export
- `verity_cartridge_v1.step` / `.stl` — inner clear vial + swatch holder
- `assembly_notes.md` — tolerances for the keyed snap-fit alignment between carrier and cartridge
